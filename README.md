# emailUPB — Panel de estudiante

Implementación en React/Vite basada en las pantallas adjuntas.

## Incluye

- Panel principal del estudiante.
- Barra lateral negra con `Solicitar`, `Solicitudes enviadas` y `Cambiar Contraseña`.
- Lista de solicitudes.
- Modal de creación de solicitud.
- Tipo `otro` por defecto.
- Formulario específico para `licencia`, incluyendo:
  - motivo de licencia
  - periodo de licencia
  - carga de documento JPG/JPEG/PDF
- Formulario específico para `dar de baja la materia`.
- Botones `Cancelar` y `Enviar Solicitud`.
- Diseño responsive básico.

## Ejecutar

```bash
npm install
npm run dev
```

Luego abre la URL que muestra Vite, normalmente `http://localhost:5173`.
